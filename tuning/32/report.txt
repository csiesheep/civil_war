一句話給 owner
--------------
bot 懂了 D 之後,D 開著共軍贏 85%(D 關 58–61%)。最大的一件事不是 bot 的決定,是開局:
**每一局(3000 / 3000)綏都在第 0 回合(免費放置)就易幟**——察綏 紅 2、藍 0、灰 2,P10 讓共軍的
免費點可以放進察綏(freeAlso),共軍先放,放 2 點 = 紅 4 ≥ 藍 0 + 灰 2 + S 2 → 控制本據 → 易幟,
國軍沒有機會回應。從這裡起:綏永遠是共軍的(+3 民心),「整編完成 5 個」的勝利(要五家全部)永遠不可能,
共軍的易幟勝只要再拿兩家(實際上 95% 是晉 + 馬)。
這是規則照寫的結果(#31 已經點名「開局的免費放置就可能易幟」),不是 bot 的錯;要不要改是 owner 的事。

一、bot 怎麼懂 D(只在 options.mechanismD 開著時生效)
-----------------------------------------------------
1. 灰依態度打折:B.GRAY_WEIGHT = { loyal: 1, neutral: 0.5, ccp: 0 }(筆記的數字)。每一點灰算國軍
   W_D.gray(1.0)× GRAY_WEIGHT[態度]。
2. 離易幟 / 整編完成還差幾步(dNeeds),逐個沒有標記的勢力,照 D 的條件:
   - 易幟:min(本據控制還差的紅 = 藍 + 灰 + S − 紅,
               統戰的路 = 態度還差幾格 × 該勢力的統戰門檻 + 本據還有補給時切斷它的紅(本據每一個不是共軍的鄰居控制還差的紅之和))。
     該勢力有帶灰的城是孤城時,這回合的結算白送一格(不算錢)。
   - 整編完成:每個有灰的據點要一次整編,每次往通共一格、通共不能整編 → 效忠裝得下兩次、觀望一次;
     裝不下、灰被打光、或最後一次整編會在本據斷補給時把它推成通共 → 這條路沒有。
     差的點數 = 還要轉的灰 + 灰變藍之後控制本據還差的藍。
   - 已經滿足條件、還沒插標記的(只有 bot 自己逐點擺的盤面會有)算已經拿到,所以擺放看得到「這一點下去就易幟」。
   - 兩組差距照舊進 markerRoad(3 個易幟 / 5 個整編完成,sealWinSoon 照讀)。
3. 拿到的 D 標記是永久的,值它在瞬間勝利裡的份:最後一個就是勝利(1000),前面的平分 MARK_WIN(60)→
   易幟 60 / 2 = 30、整編完成 60 / 4 = 15。(D 關時 W.mieHeld = W.sealHeld = 1 不動。)
4. 整編 / 統戰的候選:引擎給的每一個目標 / 勢力(行動回合與行動點的選擇),照一般候選評估;
   去掉自殺的整編(勢力觀望、本據斷補給:整編把它推成通共 = 當場易幟),除非每個候選都是。
5. 最後一個易幟不漏:winTargets 在 D 底下是「沒有標記的勢力的本據」;整編完成不靠擺放。
6. D 關:評估在易幟 / 整編那一段分岔,其餘抽成 finishBoardValue(同樣的加法、同樣的順序);
   候選過濾、winTargets 都在 mechD() 後面;不多抽亂數。

這一張為了讓 bot 懂 D 而加的評估(都只在 D 開著時):GRAY_WEIGHT 項、dNeeds 取代 STATES 的需要、
D 標記值 30 / 15、自殺整編的過濾、winTargets 的本據。沒有任何為了勝率調的數字。

五、驗收沒寫到的 D 決定(tuning/32/probe-decisions.mjs)
---------------------------------------------------
1. grayOrder(共軍 2 點奇襲晉中 藍 2 灰 2):晉效忠 → 國軍 20 次都先移藍(留下效忠的灰,灰算國軍的控制;
   評估 47.47 vs 45.47);晉觀望 / 通共 → 20 次都先移灰(觀望的灰不算國軍控制、通共的灰算反方向;
   44.62 vs 33.55 / 30.05)。模擬裡國軍的 grayOrder 幾乎都是先移藍(230 / 231):被打到的多半是效忠的馬(蘭州)。
2. 共軍兵臨城下之前要不要先整編(馬效忠、蘭州 藍 2 灰 2 有補給、國軍控制):整編蘭州 = 馬 → 觀望 + 當場整編完成。
   一次猜測的分數 46.40,最好的擺放 48.48、奇襲 48.33 → 20 次都沒整編,差 2 分,是一個接近的決定;
   換一個猜測(另一個局面順序)它就整編。模擬裡國軍的整編多半就在第 1 回合(第一個整編完成在第 1 回合:47–49%)。
3. 免費放置:五個種子都一樣——共軍 察綏、察綏、冀中 → 綏易幟;國軍 濟南、太原、桂林、昆明。
   共軍先放,國軍來不及在察綏補藍。這就是「一句話」那一段。

六、統戰為什麼少(裁決 2 要報的)
--------------------------------
D 開三批合計:共軍的行動回合裡統戰合法 5780 次(每局約 1.9 次),選了 240 次(4.2%);另外行動點的選擇
可以統戰 1671 次,選了 164 次。沒選的 5540 次,和那一步比差多少(bot 自己一次猜測的分數):
<5:191、5–10:127、10–20:719、20–40:2288、40 以上:2060;另外 155 次那一步是當場贏的一著。
不含勝著的平均差 34–35 分。每局統戰 0 次 85–88%、1 次 12–15%、2 次 0.1–0.2%。
原因(#32 第一次留言的分析,模擬證實):統戰給的那一格態度,只要該勢力帶灰的城被切斷,結算就白送
(結算的態度下降每局約 1.3 次,統戰每局 0.13 次);而統戰合法的時機多半是開局的統戰晉(太原還有補給,
不是當場易幟)。共軍值得做的統戰是「這一步就易幟」的那種。
